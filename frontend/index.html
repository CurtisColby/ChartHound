⚠ ACTION REQUIRED — SECRET KEY NOT SET
ChartHound is running but connection saving is disabled until you set a real SECRET_KEY.
Open your docker-compose.yml and replace CHANGE_ME_GENERATE_A_STRONG_RANDOM_KEY with a real key.
How to fix it in 4 steps:
1. Run this command for your OS to generate a key:
  Linux/Mac/Unraid/TrueNAS/Proxmox: python3 -c "import secrets; print(secrets.token_hex(32))"
  Windows PowerShell: python -c "import secrets; print(secrets.token_hex(32))"
  Synology/QNAP: docker run --rm python:3.12-slim python3 -c "import secrets; print(secrets.token_hex(32))"
2. Copy the result and paste it into docker-compose.yml replacing CHANGE_ME...
3. Save the file then restart: docker compose down && docker compose up -d
4. Refresh this page — the warning disappears and full functionality unlocks.

START HERE
ChartHound turns your music library into great playlists. Follow the steps in order the first time — after that, use the “After new music arrives” routine below. Every step has a GO button that takes you to the right place.
👋 FIRST TIME?
Setup is mostly waiting the first time — that's normal. Rough times for a large library (tens of thousands of songs):
  • Connect your services — 10–15 minutes
  • First ① SCAN in Top Dogs — 10–30 minutes (later scans only add new songs)
  • Genre Engine first run — 1–3 hours (later runs only look up new albums)
  • Last.fm pass — about 3 hours, quietly in the background
You can close the browser while these run. Smaller libraries are much faster.
Checking where you are…
🔁 AFTER NEW MUSIC ARRIVES
Do these four in order whenever downloads finish, so new songs get Hit Scores and genres.
  1. Let the download finish and your media server pick it up (in Plex: ⋯ → Scan Library Files on the library).
  2. Top Dogs → ① SCAN — adds the new songs (quick, only new ones).
  3. The Retriever → ▶ RUN ENGINE, then REVIEW & WRITE — genres for the new albums.
  4. Top Dogs → ② BUILD — make or refresh playlists.

GENRE ENGINE

Gives every song one family + up to 3 styles (e.g. Rock; Classic Rock; Folk Rock) by weighing Discogs (per album), MusicBrainz and Last.fm. Songs where sources disagree are marked ⚠ CONFLICT; songs few sources know are ? LITTLE DATA. Step 1: RUN (1–3 hours the first time, cached after; re-runs only look up new music). Step 2: REVIEW & WRITE. Writes the GENRE tag only; hand-edited tracks are skipped.

📁 FOLDER RULES
Everything inside a listed folder gets that family (e.g. FULL CHRISTIAN ALBUMS → Christian); the online sources then only pick the style. ⛔ Skip leaves a folder completely alone. Click RE-VOTE after saving.
🏷 UNMATCHED TAGS
Tags the sources use that no family or style catches yet, by number of your songs. Read-only — use it to pick new styles. Hover a tag for its top artists and sources.
